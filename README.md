# CRM App Starter

This project is a lightweight CRM backend built with FastAPI and PostgreSQL.

## Purpose
- Sales (Deal) tracking
- Company-based CRM logic
- Activity & performance logging
- Designed for solo or small team usage

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker & Docker Compose

## Disclaimer
This repository is a **starter / reference implementation**.

It is not intended to be used as-is in production without:
- custom configuration
- security hardening
- environment-specific adjustments
